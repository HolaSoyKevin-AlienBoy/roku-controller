# 🎮 Roku Controller

### Un mando Roku de código abierto para PC

**Roku Controller** es una aplicación para controlar dispositivos **Roku** directamente desde una PC, sin necesidad de usar el teléfono como mando.

Creé este proyecto porque tenía una **TCL Roku TV** y no encontraba un mando para PC que me funcionara como quería. Así que, en lugar de seguir buscando, decidí hacer uno. Porque aparentemente esa era la solución razonable. 💀

## ✨ Características

* 🎮 Control remoto Roku desde PC
* 💻 Aplicación para Windows
* 🔓 Código abierto
* 🐍 Código fuente disponible en Python
* 📦 Ejecutable `.exe` listo para usar
* 📺 Compatible con dispositivos Roku que permitan control desde la red

## 🚀 Cómo usarlo

1. Descarga el proyecto.
2. Abre el archivo `.exe`.
3. Asegúrate de que tu PC y tu dispositivo Roku estén conectados a la misma red.
4. Usa el mando y disfruta. 🎮

No necesitas instalar Python si utilizas la versión `.exe`.
